# Python Forge

Персональный тренажёр, который я создал для подготовки к работе Python Backend / Automation / AI Backend Developer.

## Зачем этот проект

Я хорошо понимаю backend-архитектуру, FastAPI, PostgreSQL, автоматизации и продуктовую логику, но хочу укрепить самостоятельное написание Python и SQL без подсказок AI. Поэтому Python Forge построен вокруг практики:

1. сначала я читаю условие;
2. самостоятельно пишу код;
3. запускаю реальные проверки;
4. разбираю первую ошибку;
5. повторяю навык в новой задаче;
6. возвращаюсь к слабым темам через интервальные повторы.

Главный критерий прогресса — доказанное умение решать задачи, а не время в приложении.

## Что уже есть

- три режима: Practice, Interview, Production;
- Python core как последовательный модуль из 12 блоков;
- изменённые задачи для повторения навыка, а не механическое повторение текста;
- консоль с первой реальной ошибкой и компактным журналом проверок;
- редактор с подсветкой Python и SQL;
- теория с письменными ответами;
- вкладка «Ваши решения» под редактором;
- сохранение попыток, времени, подсказок, уверенности и результатов;
- «Мой прогресс» с прочитанными главами и решёнными задачами;
- roadmap до уровня Middle Python Backend Developer;
- локальный запуск Python через Pyodide и SQL-проверки в браузере;
- адаптивный подбор следующей задачи по истории ошибок и самостоятельности.

## Полный учебник

В проект добавлены три моих учебных источника без сокращения содержания:

- Python_Fundamentals_I.md — типы, объекты, изменяемость, условия, циклы, строки, отладка и собеседования;
- Коллекции_итерации_и_вложенные_структуры_полная_версия.md — list, tuple, set, dict, comprehensions, вложенные структуры, сложность и production-паттерны;
- Функции_в_Python_полная_версия.md — параметры, области видимости, замыкания, генераторы, декораторы, typing и production-практика.

Тексты доступны во вкладке «Теория». Навигация разбивает материалы на главы, но исходный текст сохраняется полностью. У каждой главы есть поиск, оглавление, кодовые примеры, письменная проверка понимания и автоматическая отметка прочтения.

## Темы

Python core, коллекции, функции, исключения, OOP, итераторы и генераторы, декораторы, typing, async, testing, HTTP/FastAPI, PostgreSQL/SQL и работа с внешними сбоями.

## Запуск локально

Нужен Node.js 22.13+.

    npm install
    npm run dev

После запуска откройте http://localhost:5173.

Для production-сборки:

    npm run build
    npm run start

## Структура

- app/ — страницы и серверные маршруты;
- components/ — рабочая область задачи, теория и roadmap;
- lib/ — курс, задачи, адаптивная логика и учебник;
- public/course-sources/ — полные исходные материалы курса;
- public/python-worker.js и public/sql-worker.js — проверка решений;
- tests/ — проверки учебного маршрута, задач и сохранности исходных материалов.

## Проверка проекта

    python3 tests/core-content.py
    python3 tests/source-course.py
    node tests/learning-route.mjs

Проект создан и развивается мной как личная система подготовки к реальным backend-собеседованиям и работе.
